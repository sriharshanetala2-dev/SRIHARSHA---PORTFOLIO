# NETALA SRIHARSHA | Professional Portfolio

A premium, high-performance portfolio built with Next.js, Firebase, and AI-driven features.

## Features
- **AI Brand Engine**: Generates unique brand identities including tech stacks and visual marks.
- **Interactive Student Dashboard**: A simulated enterprise environment for academic data.
- **Project Showcase**: Highlights innovative solutions in Java, AI, and Network Engineering.
- **Direct Contact**: Integrated with Firebase Firestore for real-time lead management.

## Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS & ShadCN UI
- **Database/Auth**: Firebase Firestore
- **AI**: Google Genkit & Gemini 2.5 Flash / Imagen 4.0

## Getting Started

1. **Setup Environment**:
   Create a `.env` file with your Firebase credentials.

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Run Development Server**:
   ```bash
   npm run dev
   ```

## Development
This project uses Genkit for AI flows. You can start the Genkit developer UI with:
```bash
npm run genkit:dev
```

# NETALA SRIHARSHA | Professional Portfolio

A high-performance industrial portfolio showcasing expertise in Software Development, Full Stack Engineering, and AI Systems. Optimized for enterprise visibility and mobile-scale logic.

## 🚀 Public Hosting (Free Tier)
This application is ready for **Firebase App Hosting** (Free Spark Plan). To host your app with public visibility for free:

1. **Connect GitHub**: Push this code to a GitHub repository.
2. **Firebase Console**: Go to [Firebase Console](https://console.firebase.google.com/), create a project, and select **App Hosting**.
3. **Connect & Deploy**: Select your GitHub repo. Firebase will automatically detect the Next.js 15 configuration and deploy it to a public `.web.app` domain.
4. **Environment Variables**: Add your `NEXT_PUBLIC_FIREBASE_*` keys in the App Hosting dashboard settings.

## 🛠 Tech Stack
- **Framework**: Next.js 15 (App Router / Turbopack)
- **Styling**: Tailwind CSS, ShadCN UI, Lucide Icons
- **Logic**: Google Genkit (AI), Firebase (Firestore/Auth)
- **Typography**: Space Grotesk (Headlines), Inter (Body) - 100% Upright Policy

## 📝 Features
- **Professional Timeline**: Unified registry of work and academic milestones (Most Recent First).
- **Industrial HUD**: Persistent side-by-side technical metrics on all devices.
- **Gmail Sync**: Direct synchronization of contact data to Gmail compose window.
- **Neural UI**: Animated grid backgrounds and logic-scan lines for a "running system" aesthetic.
